# ParcelHub 快递聚合

一款聚合各电商平台取件码与身份码的 Android App。收到取件短信自动识别，底部一键拉起淘宝/拼多多/菜鸟/顺丰/京东身份码。

## 功能

### 取件码管理
- **短信自动解析**：收到取件短信后自动提取取件码、驿站名、快递公司，存入本地
- **手动添加**：右上角 + 号，手动输入取件码、取件地址、快递公司
- **待取 / 已取双栏**：点卡片复制取件码，标记已取/撤销
- **长按删除**：长按卡片弹出删除确认
- **新短信通知**：收到取件短信自动弹通知

### 一键拉起身份码
- 底部胶囊栏显示手机上已安装 App 的真实图标（未安装则降级为品牌色圆标）
- **淘宝**：`tbopen://` 直达身份码 H5
- **拼多多**：`pinduoduo://` 直达取件包
- **菜鸟/支付宝**：`alipays://` 直达菜鸟身份码
- **顺丰**：拉起顺丰 App
- **京东**：拉起京东 App
- **长按拖拽排序**：底部栏图标可自由排序，顺序自动保存

### 快递查询
- 右上角搜索按钮，输入快递单号查询物流轨迹
- 自动识别快递公司，识别失败可手动选择
- 显示最新轨迹、状态标签、预计到达时间
- 查询结果可一键保存到本地列表

### 桌面 Widget
- 长按桌面添加「快递聚合」小组件，显示待取数量

### UI
- 深色玻璃拟态风格，纯黑背景
- 底部栏 Haze 毛玻璃模糊（Android 12+ 真模糊，低版本半透明降级）

## 技术栈

- Kotlin + Jetpack Compose + Material 3
- MVVM（手写 ViewModel，无 DI 框架）
- SharedPreferences + JSON 持久化（不引 Room）
- OkHttp 网络请求（快递100 公开接口）
- Haze 毛玻璃
- 最低支持 Android 8.0（API 26）

## 权限说明

- `RECEIVE_SMS` / `READ_SMS`：监听取件短信
- `POST_NOTIFICATIONS`：新取件码通知
- `INTERNET`：快递单号查询

## 已知限制

- 快递查询走快递100 公开接口，有频率限制，勿连续高频查询
- 顺丰/京东的微信小程序拉起 path 待真机实测
- 短信解析基于规则，遇到奇葩签名可能漏识别
- 预计到达时间为粗估，非官方数据

## 构建

本地：
```
gradle assembleDebug
```

云端：push 到 main 自动触发 GitHub Actions，从 Actions 页下载 `ParcelHub-debug`。
