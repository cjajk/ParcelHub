# ParcelHub 快递聚合

一款聚合各电商平台取件码与身份码的 Android 本地小工具。收到取件短信自动识别，一键拉起各平台身份码，不用在 App 之间反复跳转找取件码。

## 功能

### 📱 取件码管理
- **短信自动解析**：收到取件短信后自动提取取件码、驿站名、快递公司，存入本地
- **首次启动回扫**：装上 App 自动扫描最近 7 天的取件短信，不用等下一条
- **手动添加**：右上角 + 号，手动输入取件码、取件地址、快递公司
- **短信导入**：顶部剪贴板导入按钮，粘贴短信内容自动解析，支持多条批量导入
- **待取 / 已取双栏**：点卡片复制取件码，标记已取/撤销，已取快递号加横线变淡
- **删除动画**：记录消失时下面的记录自动向上滑动补位
- **长按删除**：长按卡片弹出删除确认
- **新短信通知**：收到取件短信自动弹通知

### ⚡ 快捷取件
底部第三个 Tab，分两组：
- **身份码组**：一键拉起淘宝/拼多多/菜鸟/顺丰/京东的取件身份码
- **查看待取组**：直接打开淘宝/拼多多/京东的待取快递列表
- 顺丰未安装时自动跳微信顺丰小程序

### 📦 快递查询
- 右上角搜索按钮，输入快递单号查询物流轨迹
- 自动识别快递公司，识别失败可手动选择
- 显示完整物流轨迹、状态标签
- 查询结果可一键保存到本地列表，保存前可编辑取件码和驿站名
- 快递100密钥可在搜索页自行配置（附操作流程）

### ⏰ 快递提醒
- **单个快递提醒**：每个快递卡片可单独设置提醒日期和时间，默认今天，禁选过去时间
- **每日统一提醒**：右上角闹钟按钮，一键设置每日统一提醒时间
- **重启恢复**：手机重启后自动恢复所有闹钟

### 📊 桌面 Widget
- 长按桌面添加「快递聚合」小组件
- 显示待取快递数量
- 点击取件码直接复制

### 🎨 UI
- 深色玻璃拟态风格，纯黑背景
- 底部栏 Haze 毛玻璃模糊（Android 12+ 真模糊，低版本半透明降级）
- **侧边栏转置键**：长按拖拽可上下移动侧边栏位置，固定大小不拉伸，位置自动记忆
- 横竖切换动画流畅

## 技术栈

- Kotlin + Jetpack Compose + Material 3
- MVVM（手写 ViewModel，无 DI 框架）
- SharedPreferences + JSON 持久化
- OkHttp 网络请求（快递100 公开接口）
- Haze 毛玻璃
- 最低支持 Android 8.0（API 26），目标 SDK 35

## 权限说明

- `RECEIVE_SMS` / `READ_SMS`：监听取件短信 + 首次回扫
- `POST_NOTIFICATIONS`：新取件码通知 + 到点提醒
- `SCHEDULE_EXACT_ALARM`：精确闹钟提醒
- `RECEIVE_BOOT_COMPLETED`：重启后恢复闹钟
- `INTERNET`：快递单号查询
- `QUERY_ALL_PACKAGES`：检测已安装 App 并拉起

## 已知限制

- 快递查询走快递100 公开接口，有频率限制，勿连续高频查询
- 短信解析基于规则，遇到奇葩签名可能漏识别
- 顺丰微信小程序在 Android 上无法直接拉起，降级为打开顺丰 App

## 构建

本地：
```
gradle assembleDebug
```

云端：push 到 main 自动触发 GitHub Actions，从 Actions 页下载 `ParcelHub-debug` APK。
